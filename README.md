# 轨道炮火力控制器（Orbital Strike Fire Control）

一款整合历代轨道炮（OSC）火力控制计算器的网页应用，支持版本选型、参数输入、结果输出与一键复制，移动端友好。

## 功能特性

- **多版本支持**：1.0 / 2.0 / 3.0 / 2.3（特殊版）/ 4.0·4.3（同版本）/ 6.0·6.1（同版本）/ 6.1MS
- **版本分组**：常规版本栏 + 特殊版本栏（2.3），避免版本混淆
- **多种输出形式**：翻页数档位、方块名称与数量、13×5 格子点亮矩阵
- **一键复制结果**：计算结果、格子矩阵字符画（■/□）均可复制
- **移动端适配**：手机竖屏友好，大触控目标，格子矩阵自适应屏幕
- **防滥用机制**：每次计算 5 秒冷却
- **使用统计**：右上角显示累计计算次数

## 版本说明

| 版本 | 类型 | 输出内容 |
|------|------|----------|
| 1.0 | 翻页 | 8 方向 Total/Count/Course/Fine + 页数档位 |
| 2.0 | 翻页 | 5 档页数（0-9 / 00-90 / 000-900 / 1k-9k / 00k-90k） |
| 3.0 | 翻页 | 与 2.0 共用同一公式 |
| 2.3 | 方块数量（特殊版） | 方块档位 × 数量 + 总刻度 + 飞行时间 |
| 4.0 / 4.3 | 方块数量（同版本） | Count/Trim + 方块档位数量 + 飞行时间 |
| 6.0 / 6.1 | 格子点亮（同版本） | 13×5 格子矩阵 + XYZ 三轴参数 + Good Codes 码表 |
| 6.1MS | 格子点亮 | 13×5 格子矩阵 + Coarse/Fine/Diff/Count + 时间估计 |

## 使用说明

1. 选择轨道炮版本（常规 / 特殊分组）
2. 按版本要求填写参数（原点坐标、目标坐标、开火模式、Nuke Size、Passcode 等）
3. 点击「计算」，等待冷却结束后可再次计算
4. 查看结果并一键复制
